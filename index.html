Materi 01

Apa itu Agent AI?

Agent AI adalah program komputer yang bisa mengambil keputusan secara mandiri berdasarkan informasi dari lingkungannya untuk mencapai tujuan tertentu.

📌 Definisi Sederhana

Bayangkan kamu punya asisten yang bisa melihat situasi di sekitarnya, berpikir apa yang harus dilakukan, lalu melakukan tindakan yang tepat — tanpa perlu kamu suruh satu per satu. Itulah Agent AI.

📖 Menurut Referensi

Menurut Russell & Norvig (2021) dalam Artificial Intelligence: A Modern Approach, sebuah agent adalah entitas yang mempersepsi lingkungannya melalui sensor dan bertindak melalui aktuator untuk mencapai tujuannya.

📝 Catatan Penting: Agent AI berbeda dengan program biasa. Program biasa hanya menjalankan instruksi yang sudah ditulis, sedangkan Agent AI bisa beradaptasi dengan situasi yang berubah-ubah secara dinamis.
Materi 02

Jenis-Jenis Agent AI

Secara umum, ada lima jenis Agent AI yang dipelajari dalam mata kuliah Kecerdasan Buatan:

📡

Simple Reflex Agent

Bertindak berdasarkan kondisi saat ini saja. Tidak punya memori. Contoh: sensor lampu otomatis.

🧠

Model-Based Agent

Punya model internal tentang dunia, bisa mengingat kondisi sebelumnya. Lebih pintar dari simple reflex.

🎯

Goal-Based Agent

Bertindak untuk mencapai tujuan tertentu. Bisa mempertimbangkan berbagai pilihan tindakan.

⚖️

Utility-Based Agent

Memilih tindakan yang memberikan keuntungan terbesar menggunakan fungsi utilitas.

📚

Learning Agent

Bisa belajar dari pengalaman dan memperbaiki performanya sendiri dari waktu ke waktu.

Materi 03

Cara Kerja Agent AI

Agent AI bekerja dalam sebuah siklus yang terus berulang. Berikut adalah tahapannya:

1

Persepsi (Sensing)

Agent menerima informasi dari lingkungannya melalui sensor. Contoh: kamera, mikrofon, atau data dari internet.

2

Pemrosesan (Processing)

Agent memproses informasi yang didapat dan mencocokkannya dengan tujuan yang sudah ditentukan.

3

Pengambilan Keputusan (Decision Making)

Berdasarkan pemrosesan, agent memilih tindakan terbaik yang harus dilakukan.

4

Tindakan (Action)

Agent melakukan tindakan melalui aktuator. Contoh: menampilkan teks, menggerakkan robot, mengirim email, dll.

5

Evaluasi & Pembelajaran (Learning)

Beberapa agent mengevaluasi hasil tindakannya untuk meningkatkan performa di masa depan.

Materi 04

Contoh Agent AI di Kehidupan Nyata

Agent AI sudah banyak digunakan di sekitar kita, meskipun kita sering tidak menyadarinya:

🔍

Google Search

Mesin pencari yang bisa memahami maksud pencarian kita dan menampilkan hasil yang relevan.

🛒

Rekomendasi Shopee/Tokopedia

Agent yang merekomendasikan produk berdasarkan riwayat belanja dan pencarian kita.

🎵

Spotify / YouTube

Merekomendasikan lagu atau video yang kemungkinan besar kita suka berdasarkan kebiasaan.

🚗

Mobil Self-Driving

Kendaraan otonom yang bisa mengemudi sendiri menggunakan sensor dan AI untuk navigasi.

💬

Chatbot / Virtual Assistant

Siri, Google Assistant, ChatGPT yang bisa menjawab pertanyaan dan membantu tugas.

🎮

NPC dalam Game

Karakter game yang bergerak dan bereaksi secara cerdas terhadap tindakan pemain.

Security Config

🛡️ HTTP Security Headers

Website ini di-deploy dengan Cloudflare Pages menggunakan file _headers yang mengaktifkan security headers berikut secara otomatis:

X-Frame-Options
DENY
Mencegah website di-embed dalam iframe oleh situs lain. Melindungi dari serangan Clickjacking.
X-Content-Type-Options
nosniff
Mencegah browser menebak MIME type dari file. Melindungi dari MIME-type sniffing attack.
Referrer-Policy
same-origin
Membatasi informasi referrer hanya dikirim ke domain yang sama. Menjaga privasi user.
Permissions-Policy
camera=(), microphone=(), geolocation=()
Menonaktifkan akses ke kamera, mikrofon, dan lokasi. Mengurangi attack surface pada browser.
Content-Security-Policy
default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'
Membatasi sumber konten yang boleh dimuat browser. Perlindungan utama terhadap serangan XSS (Cross-Site Scripting).
ℹ️ Verifikasi status aktif: buka DevTools (F12) → Network → klik index.html → Response Headers
